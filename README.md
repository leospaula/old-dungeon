# Masmorra Clássica

Dungeon crawler em voxel, por turnos e em grupo, com as regras do D&D Básico (B/X) via retroclones abertos. Feito em Godot 4 para rodar no navegador.

- **Documentação** (design, regras B/X, aventuras, setup e MCPs): Personal Brain → `~/Documentos/Personal Brain/RPG/Masmorra Clássica/`
- Especificação técnica: [docs/formato-aventura.md](docs/formato-aventura.md)

## Rodar
1. Instale o Godot 4 (versão padrão, não a .NET): https://godotengine.org/download
2. Abra o Godot → Import → selecione `project.godot` desta pasta.

## Exportar para web
Project → Export → Web, com *Thread Support* desligado (single-threaded).
